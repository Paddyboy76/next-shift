# Mission 14 — Spoken Handover, Only If Green

First prove the core system is still green.

Then evaluate Gemini-native spoken handover/audio intake.

Implement only if:

- it materially improves the judge experience;
- it uses real Google capability;
- it feeds the same governed operational intake path;
- transcription/extraction is auditable;
- text fallback remains stable;
- security and safety boundaries remain unchanged;
- it does not destabilize the four-minute demo.

Use synthetic non-clinical operational language only.

If spoken handover would reduce reliability or cannot be made genuinely integrated, deliberately skip it and document why. A justified skip may still be `PHASE_RESULT: PASS`.
