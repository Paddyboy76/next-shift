# Mission 10 — Registry + Memory + OpenTelemetry

Close the most important platform/judge gaps.

Deliberately evaluate and, where supported and valuable, complete:

## Agent Registry / lifecycle

Make specialist identity, capability, lifecycle/discovery, or deployed-agent registration real and judge-visible using the appropriate Google Agent Platform capability.

Do not build a fake local registry merely to claim registry usage.

## Memory

Use Memory Bank only for non-authoritative historical operational intelligence.

Desired value:

- recurring operational patterns;
- cross-shift trends;
- repeated bottlenecks;
- timing patterns;
- department/capability trends;
- actionable plain-English recommendations.

Memory must:

- show provenance;
- remain advisory;
- never establish current issue status;
- never silently mutate Firestore;
- never override authoritative current state.

## Observability / OpenTelemetry

Make the lifecycle trace visible through real observability:

handover
→ issue
→ event
→ route
→ specialist
→ action
→ evidence
→ verifier
→ closure

Prefer native Google Agent Platform/OpenTelemetry evidence where practical.

Never fabricate telemetry.
